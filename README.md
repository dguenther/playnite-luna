# Amazon Luna Catalog Browser for Playnite

> [!NOTE]
> This addon was created for personal use and may not support different OSes, languages, or non-US Luna accounts. PRs and issues welcome!

Display the Amazon Luna game catalog in Playnite and optionally import Luna games into your library. Once games are imported into your library, clicking Play or Install launches the game in your browser.

Settings to enable auto-import/syncing are available in Add-ons > Extensions settings > Libraries > Amazon Luna.

## Install

You can install the addon by downloading the [latest release](https://github.com/dguenther/playnite-luna/releases), then dragging and dropping the .pext file onto your Playnite window. Updates work the same way.

I'd like to submit it to the addon database in the future, but addon database submissions are [currently on hold](https://github.com/JosefNemec/PlayniteAddonDatabase).

## Build and test

First, install the .NET 10 SDK, then run the following steps:

```sh
dotnet restore AmazonLuna.sln --locked-mode
dotnet build AmazonLuna.sln -c Release --no-restore
dotnet test tests/LunaCatalog.Tests/LunaCatalog.Tests.csproj -c Release --no-build
```

Compilation works on Linux, but you'll have to copy the .pext to a Windows machine for testing (since Playnite is Windows-only)
